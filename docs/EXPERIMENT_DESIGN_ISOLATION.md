# 机制隔离实验设计（v1.0）

## 核心问题
"起始帧导致的摔倒率差异，是初始化状态问题还是内容难度问题？"

## 实验设计：2×2 配对

### 固定量
- 同一 session 的同一锚点帧（如 f200）
- 完全相同的未来 300 帧参考
- 相同的评估器、随机种子、时域

### 自变量（2×2 因子设计）

| 条件 | 物理初始化 | 策略历史 |
|------|-----------|---------|
| A | 常规 reset（从锚点帧姿态） | 冷启动 |
| B | 动态 checkpoint（preroll 产生） | 冷启动 |
| C | 常规 reset | 恢复 preroll 历史 |
| D | 动态 checkpoint | 恢复 preroll 历史 |

### 物理状态定义
qpos, qvel, root 线/角速度, 执行器状态, 接触状态

### 策略历史定义
RNN hidden state, 观测栈, 滤波器状态

### Preroll 实现
1. 从锚点帧前 60 帧（2 秒）开始跑
2. 策略正常跟踪这 60 帧
3. 保存完整模拟器状态 + 策略内部状态
4. 从保存的状态恢复，继续跟踪未来 300 帧

### 主终点
固定 300 帧内是否摔倒（不删早期失败）

### 次级终点
- 首秒失败率
- 摔倒时间
- 跟踪误差（orientation_max_deg）
- 恢复成功率（preroll 是否到达锚点）

### 样本量
- 10 场 × 4 条件 × 1 seed = 40 episodes
- 若 preroll 成功率 ~80%，实际 ~32 episodes
- 按会话配对分析

### 预期结果解读

| 如果... | 则... |
|---------|-------|
| A 摔倒，B 不摔 | 物理初始化是主因 |
| A 摔倒，C 不摔 | 策略历史是主因 |
| A 摔倒，D 不摔 | 初始化+历史共同作用 |
| A=B=C=D | 起始帧效应是内容差异，非初始化 |
| B 摔倒但 A 不摔 | preroll 反而有害（需调查） |

### 技术前提
- MuJoCo 保存/恢复完整状态（mj_state）
- 策略 RNN hidden state 保存/恢复
- 验证恢复后重放等价性（同状态同动作）
