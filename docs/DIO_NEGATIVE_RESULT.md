# DIO 首次实验结果（负结果）

## 实验设计
- 对 8 个 f0 摔倒的 session，用 DIO 生成替代初始关节角
- 每个尝试 3 个 DIO 候选（共 24 次 MuJoCo 评估）
- 替换参考帧 0 的关节角，其他帧不变

## 原因分析

### 1. 训练数据太少（52 个正样本）
扩散模型可能只学到了训练数据的均值，生成的是"平均好姿态"而非针对特定参考的最优初始化。

### 2. 方法本身的问题
简单替换帧 0 的关节角不够——因为：
- **策略内部状态（RNN hidden）仍是冷启动**：不管关节角怎么变，策略的 recurrent state 从零开始，需要时间才能"理解"当前状态
- **速度不匹配**：参考帧 0→1 有隐含速度，但替换帧 0 后这个速度关系被打乱
- **接触状态**：初始关节角变了但接触力/支撑状态可能不对

### 3. 更深层的问题
Onset 脆弱性可能不是"初始姿态不好"的问题，而是：
- 策略冷启动的 recurrent state 没有运动上下文
- 从静止开始的动力学与参考的动作动力学不匹配

## 学到什么

这个负结果排除了"简单替换初始关节角就能解决 onset 问题"的假设。指向的真正原因是：

1. **策略冷启动** > 初始姿态（最重要的因素）
2. 需要的不是"更好的初始姿态"而是"策略的热身"

## 下一步方向修正

| 方向 | 原因 | 预期 |
|------|------|------|
| ~~替换初始关节角~~ | ❌ 已证明无效 | 放弃 |
| **速度匹配初始化** | 设置正确的初始速度 | 可能部分有效 |
| **短前滚 warm-up** | 让策略跑几步建立 internal state | 最有前景 |
| **参考平滑过渡** | 在参考前加过渡段 | 类似 warm-up |
