# A+C 合并路线：DIO 算法创新 × 穿戴数据应用

## 合并后的论文故事线

```
发现问题：跟踪策略对起始帧敏感（80% vs 40% 摔倒率差异）
    ↓
算法创新：DIO——扩散初始化优化器（核心贡献）
    ↓ 方法：条件扩散模型学习"什么是好的初始化"
    ↓ 输入：参考动作前 N 帧 → 输出：最优初始状态
    ↓
数据应用：在 115+ 场穿戴 IMU 日常动作上大规模验证
    ↓ 体现：独家穿戴数据的价值（不是 AMASS 公开数据）
    ↓
部署框架：预测 → 优化初始化 → 可靠跟踪
```

## 论文三大贡献

| # | 贡献 | 类型 | 创新点 |
|---|------|------|--------|
| 1 | DIO 扩散初始化优化器 | 算法 | 首次将扩散模型应用于跟踪初始化 |
| 2 | 穿戴数据大规模基准 | 数据 | 115+ 场独家 IMU 日常动作 |
| 3 | 多起始帧评估协议 | 方法论 | 标准化起始敏感性量化 |

## 执行计划（三阶段）

### Phase 1：DIO 实现（第 1-2 周）

#### 1.1 数据准备（已有，无需新采集）
从 390 个现有评估中提取训练数据：
- 输入：参考前 30 帧（joint angles + velocities）
- 正样本标签：成功起始的初始状态（fall=false 的那些）
- 负样本标签：失败起始的初始状态（fall=true 的那些）

#### 1.2 模型架构（小型，单卡可训）
```
条件编码器：
  参考前缀 (30×58) → Transformer(2层) → 256维

扩散网络：
  输入：噪声初始状态 (58) + 条件embedding (256) + 时间步
  网络：MLP (58→256→256→256→58)
  损失：去噪分数匹配
  步数：T=100（DDPM 简化版）

推理：
  采样 K=10 个候选 → MuJoco 快速评估前 30 步 → 选最优
```

#### 1.3 训练（估计 2-4 小时，单卡 3090）
- 训练数据：~120 个成功起始 + ~120 个失败起始（去重后）
- 对比实验：生成 vs 帧0 / 随机 / 延迟起始

#### 1.4 预期结果
| 方法 | 起始摔倒率 | 备注 |
|------|-----------|------|
| 帧 0 起始 | ~80% | 现状 |
| 随机起始 | ~50% | 基线 |
| 延迟 50 帧 | ~40% | 简单缓解 |
| DIO 生成 | **目标 <30%** | 算法贡献 |

#### 2.2 大规模对比实验
- 5 个策略 × 50 场 × 5 起始帧 × 4 种初始化方法
- 总评估：5 × 50 × 5 × 4 = **5000 次**
- 4 路并行 MuJoCo：~4 小时

#### 2.3 统计功效
- n=50 场 → CI 缩窄到 ±10%
- McNemar test → p < 0.001（如果效应保持）
- 足够发正式论文
