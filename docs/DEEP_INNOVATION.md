# 深度创新方向（超越"发现问题+简单修复"层面）

## 现有贡献的不足
- 系统量化 → 别人隐式知道（RGMT/SuperMimic）
- 评估协议 → 方法论贡献，非算法贡献
- 延迟起始 → 太简单，不算创新
- 课程训练 → RGMT 已做（随机不稳定初始化）

**核心缺失：一个真正新颖的算法贡献**

---

## 方向 1：初始化状态优化（Initialization-State Optimization）

### 核心思想
将"从哪里开始跟踪"形式化为**优化问题**：
$$\min_{q_0, \dot{q}_0, h_0} \quad \mathbb{E}\left[\sum_{t=0}^{T} ||\pi(s_t) - r_t||^2\right]$$
其中 $(q_0, \dot{q}_0, h_0)$ 是初始状态（关节角+速度+策略隐状态），$\pi$ 是跟踪策略，$r_t$ 是参考。

### 为什么新颖
- **没人把初始化当优化问题**：PHC/SONIC 用固定帧0；RGMT 用随机采样；SuperMimic 用世界模型隐式处理
- **有理论深度**：连接到最优控制（LQR-like）和逆强化学习
- **有实用价值**：找到的初始化可以直接部署

### 实现方案
**方案 A（梯度法）**：
1. 固定策略网络参数
2. 对初始状态 $(q_0, \dot{q}_0)$ 求梯度
3. 用 BPTT 通过策略的前 K 步回传梯度
4. 优化初始状态使前 K 步跟踪误差最小

**方案 B（模拟器搜索法）**：
1. 在参考帧 0 附近的状态空间中搜索
2. 用模拟器快速评估每个候选初始化
3. 选出摔倒概率最低的初始化

**方案 C（学习方法）**：
1. 训练一个小网络：输入=参考前 N 帧 → 输出=最优初始状态
2. 用 RL（reward=后续跟踪性能）或监督学习
3. 部署时用这个网络初始化

### 与现有工作的差异
| 方法 | 初始化方式 | 我们的差异 |
|------|-----------|-----------|
| PHC/SONIC | 固定帧 0 | 被动接受，不优化 |
| RGMT | 随机采样 | 无目标性，靠量堆 |
| SuperMimic | 世界模型 | 需要世界模型，我们直接优化 |
| **我们** | **显式优化** | **主动寻找最优起始状态** |

### 可行性
- 方案 B 最简单（模拟器评估+搜索），可以在当前 MuJoCo 环境实现
- 方案 A 需要可微分模拟器（MuJoCo MJX 或 Isaac Lab 的可微分版本）
- 方案 C 需要训练新网络（可以用现有 FineTuneTrainer）

## 方向 2：起始敏感性作为泛化能力的代理指标

### 核心思想
**假设**：对起始帧越敏感的策略，泛化能力越差

$$\text{OnsetSensitivity} = \text{Var}_{f \in \text{starts}}(\text{fall\_rate}(f))$$

如果 OnsetSensitivity 与 unseen motion 上的失败率高度相关，
那么它就是一个**廉价的泛化能力预测器**。

### 为什么有价值
- 评估泛化能力通常需要大量 unseen 动作（昂贵）
- 起始敏感性只需要在**已有动作**上做多起始帧评估（便宜）
- 如果验证了这个相关性，就有了一个实用的模型选择标准

### 验证实验
1. 对多个策略（035/M4B/M9C/M11D/M17）计算 OnsetSensitivity
2. 对同一组策略在 v7 未见动作上评估失败率
3. 计算两者相关性

### 潜在影响
- 给社区一个新的模型评估维度
- 可能揭示"为什么某些策略泛化更好"的机制

## 方向 3：对比初始化训练（Contrastive Initialization Training）

### 核心思想
训练时加入**不变性目标**：同一动作、同一内容，不同初始化 → 策略输出应相似

$$\mathcal{L} = \mathcal{L}_{track} + \lambda \cdot \mathcal{L}_{invariance}$$
$$\mathcal{L}_{invariance} = ||\pi(s_t | \text{init}_A) - \pi(s_t | \text{init}_B)||^2$$

### 为什么新颖
- 对比学习/invariance learning 在 CV 中很成熟
- 但**从未应用于运动跟踪的初始化**
- RGMT 的随机初始化是无目标的；我们的对比初始化是**有目标的**（显式优化不变性）

### 实现方案
1. 每个 episode 采样两个不同起始帧
2. 同一策略分别从两个起始帧跟踪
3. 在相同内容段计算策略输出差异
4. 将差异作为额外 loss（鼓励不变性）

### 与 RGMT 的差异
RGMT: "随机初始化，希望策略自己学会鲁棒"（隐式）
我们: "显式优化初始化不变性"（显式目标）
